## Требования

- Node.js v24.20.0
- pnpm

## Настройка

1. Скопируйте `.env.example` в `.env`.
2. При необходимости укажите `VITE_GREEN_API_URL` — необязательный адрес `apiUrl` по умолчанию из личного кабинета GREEN-API, и `VITE_LID_MODE` — режим адресации чата. Если `VITE_GREEN_API_URL` не задан, адрес нужно указать на странице входа.

Например:

```env
VITE_GREEN_API_URL=https://api.green-api.com
VITE_LID_MODE=true
```

## Требования к инстансу GREEN-API

- Инстанс WhatsApp должен быть авторизован: отсканируйте QR-код в личном кабинете GREEN-API.
- Поле webhook URL в настройках инстанса должно быть пустым.
- `VITE_LID_MODE=true` (значение по умолчанию) должен соответствовать включенному `EnableLidMode`: сообщения от собеседников без созданного чата не отображаются.
- `VITE_LID_MODE=false` должен соответствовать выключенному `EnableLidMode`: сообщение от нового собеседника с `chatId` вида `<номер>@c.us` автоматически создает чат. В обоих случаях групповые и прочие неподходящие `chatId` не отображаются.
- В настройках инстанса включены уведомления о статусах исходящих сообщений (`outgoingWebhook`). Без них статус отправленного сообщения не обновляется.

Установите зависимости и запустите сервер разработки:

```bash
pnpm install
pnpm dev
```

## Использование

1. Войдите, указав `idInstance` и `apiTokenInstance`.
   При необходимости нажмите «Изменить» под формой входа и укажите `https://<хост>` из личного кабинета GREEN-API. Допустимы только домены `green-api.com`, `greenapi.com` и их поддомены.
2. Создайте чат, введя номер собеседника в международном формате, например `+79991234567`.
3. Напишите сообщение и нажмите Enter для отправки. Для переноса строки используйте Shift+Enter.

## Известные ограничения

- Поддерживается только WhatsApp и только текстовые сообщения.
- В режиме `VITE_LID_MODE=true` входящие сообщения от собеседников, для которых чат ещё не создан, не отображаются.
- Сообщения, отправленные с телефона, и история переписки не отображаются.
- Чаты и сообщения хранятся только в памяти и теряются при перезагрузке страницы или выходе из приложения.
- API-токен передаётся в пути URL, потому что этого требует API GREEN-API.
